# Decision Trees, Bagging, and Boosting for Face Recognition

## Overview

This project studies decision trees and ensemble learning methods for multiclass face recognition using the **Olivetti Faces dataset**. It compares a single decision tree, bootstrap aggregating (bagging), and multiclass AdaBoost using the SAMME algorithm.

The experiments evaluate classification performance, ensemble behavior, out-of-bag (OOB) estimates, robustness to image occlusion, and the bias–variance trade-off.

## Dataset

The project uses the Olivetti Faces dataset, containing 400 grayscale face images from 40 individuals.

- **Image resolution:** 64 × 64 pixels
- **Number of classes:** 40 identities
- **Features:** 4,096 flattened pixel values per image
- **Training set:** 240 images
- **Validation set:** 80 images
- **Test set:** 80 images

The data are split separately within each identity, using 6 training images, 2 validation images, and 2 test images per identity.

The configured random seed is `003` (integer value `3`). The generated dataset and split are saved as `olivetti_faces_final.npz` for reuse by the implementation notebook.

No PCA or other dimensionality reduction is applied.

## Experimental Protocol

### Decision Tree

A decision-tree classifier is evaluated across multiple maximum-depth and minimum-leaf-size settings. Hyperparameters are selected using validation accuracy.

### Bagging

Bagging is implemented by training decision trees on bootstrap samples drawn from the training set. The experiments examine performance as the number of estimators increases, along with OOB accuracy, prediction disagreement, and vote margins.

### SAMME Boosting

The multiclass SAMME algorithm is implemented from scratch. The experiments evaluate different tree depths and boosting-round counts, using validation accuracy for model selection.

### Occlusion Robustness

A masked test set is created by setting the central 16 × 16 pixel region (rows 24–39 and columns 24–39) to zero. Models are trained on clean images and evaluated on both clean and masked test images.

### Bias–Variance Analysis

Selected models are refitted on repeated bootstrap resamples of the training data. Their prediction bias, variance, and test accuracy are compared to study the effect of model complexity and ensemble learning.

## Reproducibility

- Use the configured seed consistently.
- Generate the dataset split before running the main implementation notebook.
- Reuse the saved split for comparisons between models.
- Select hyperparameters using validation data, not test accuracy.
- Run the notebooks from top to bottom to regenerate results and figures.
